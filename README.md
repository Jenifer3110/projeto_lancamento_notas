# Projeto de Automação Robótica de Processos (RPA)

## Objetivo
Desenvolver um programa em Python para auxiliar no processamento e lançamento de notas acadêmicas.

## Funcionalidades atuais
- Processar dados de alunos fictícios.
- Calcular a nota final usando a média simples das quatro notas de teste.
- Verificar matrículas (RA) duplicadas.
- Exportar os resultados para um arquivo CSV.

## Tecnologias utilizadas
- Python
- Visual Studio Code
- Arquivos CSV

## Como executar
1. Instale o Python.
2. Abra a pasta do projeto no VS Code.
3. Execute no terminal:

   `python "automação_notas.py"`

4. O programa gera o arquivo `notas_alunos.csv`.

## Observação
Esta é uma versão inicial de teste. A fórmula das notas e a integração com o portal acadêmico ainda precisam ser ajustadas conforme os requisitos do professor.

Os dados utilizados nesta versão são fictícios.
